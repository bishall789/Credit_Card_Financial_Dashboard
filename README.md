# 📊 Credit Card Analytics Dashboard (Power BI)

This project is a complete **Power BI dashboard** designed to analyze **credit card transactions and customer behavior**. It provides deep insights into revenue patterns, customer segments, card usage, and business performance.
All data used in this dashboard was **imported from a SQL database** for clean, structured, and reliable analysis.

---

## 🚩 Problem Statement

Financial institutions process millions of credit card transactions every year.
However, without proper analysis, they struggle to understand:

* Which customer groups generate the most revenue
* How spending patterns vary across categories
* Which card types perform best
* How card usage (Swipe, Chip, Online) affects earnings
* Revenue trends across time, states, and customer demographics

This lack of visibility limits decision-making and business growth.

---

## 🎯 Project Objective

The goal of this project is to build a **visual, interactive, and insightful dashboard** that helps stakeholders:

* Track revenue trends across quarters & weeks
* Identify high-value customer segments
* Understand spending behavior by expense type
* Compare revenue by card category (Blue, Silver, Gold, Platinum)
* Analyze customer demographics (age, job, income, state, dependents, qualification, etc.)
* Explore usage patterns (Swipe vs Chip vs Online)
* Support strategic decisions using accurate SQL-powered data

---

## 🧩 Data Source

This project uses data **imported directly from a SQL database**:

* Credit card transaction table
* Customer demographic & income table
* Card category & usage table

Power BI connects to the SQL server, loads the tables, and applies transformations using **Power Query** before visualization.

---

## 🧩 Key Features & Insights

### **🔹 Transaction Report**

* Quarterly revenue & transaction count
* Revenue by expense type
* Card category performance
* Usage type comparison: Swipe / Chip / Online

### **🔹 Customer Report**

* Revenue by customer job type
* Interest earned by customer segment
* Revenue breakdown by:

  * Age group
  * State
  * Qualification
  * Income group
  * Marital status
  * Number of dependents




---

## ✅ Conclusion

This Power BI project transforms SQL-based credit card data into **clear, actionable insights**, helping financial institutions:

* Understand customer behavior
* Identify revenue drivers
* Enhance card service strategies
* Make smarter, data-driven decisions
